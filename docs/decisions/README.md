# Decisões de arquitetura

Uma decisão registra contexto, escolha e consequências. Os registros abaixo codificam o
comportamento já implementado; não constituem aprovação de arquitetura corporativa.
Mudanças com impacto duradouro devem acrescentar uma decisão ou substituir explicitamente
uma anterior, preservando seu histórico.

| Registro | Assunto |
|---|---|
| [0001](0001-control-and-candidate.md) | Controle confiável e candidata separados |
| [0002](0002-evidence-and-release.md) | Evidência por commit e decisão de entrega |
| [0003](0003-skills-and-adoption.md) | Skills por fase e adoção explícita |

Para registrar uma nova escolha, use [o modelo](template.md). Identifique o responsável,
a issue/PR e os critérios usados; não invente uma decisão humana ausente.
