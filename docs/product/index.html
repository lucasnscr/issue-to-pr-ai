Da issue à recuperação verificada

Documentação incremental do produto. Explore cada fase, seus critérios e as evidências disponíveis.

Um teste sintético de protocolo não comprova entrega de código ou qualidade de um modelo. Cada evidência declara seu alcance.

Issue autorizada → OpenCode + modelo local → testes independentes → PR draft → deploy → Sentinela

Limites e responsabilidades

O agente escreve código em ambiente dedicado. A validação e a publicação acontecem fora dele. Modelo, runtime e infraestrutura são escolhas independentes.

Implementar uma issue do Sentinela e monitorar o próprio Sentinela são operações diferentes. Autorreparo exige monitor externo.
